# Stop all servers

This will stop all applications which were created by
[`startServer()`](https://rstudio.github.io/httpuv/reference/startServer.md)
or
[`startPipeServer()`](https://rstudio.github.io/httpuv/reference/startServer.md).

## Usage

``` r
stopAllServers()
```

## See also

[`stopServer()`](https://rstudio.github.io/httpuv/reference/stopServer.md)
to stop a specific server.
